# ChatAppWithAI - Frontend

A modern, real-time code collaboration workspace with integrated AI assistance.

## Features
- **Real-Time Collaboration**: Work on code together seamlessly with WebSockets (Socket.io).
- **Integrated AI Assistant**: Chat with an AI (powered by Google Gemini 2.5 Flash) to generate, explain, and refactor code.
- **In-Browser IDE**: Uses WebContainers to run the code securely inside the browser.
- **Dark Mode UI**: Beautiful glassmorphism UI with Tailwind CSS.

## Tech Stack
- React
- Vite
- Tailwind CSS
- Socket.io-client
- WebContainers API

## Getting Started

1. Install dependencies:
   \`\`\`bash
   npm install
   \`\`\`

2. Set up environment variables in \`.env\`:
   \`\`\`
   VITE_API_URL=http://localhost:4000
   \`\`\`

3. Start the development server:
   \`\`\`bash
   npm run dev
   \`\`\`
